# Ekran görüntülerini ekleme

1. Uygulamayı açın ve Windows'ta `Win + Shift + S` ile görüntü alın.
2. PNG olarak bu klasöre kaydedin:

| Dosya adı | Gösterilecek ekran |
| --- | --- |
| `login.png` | Giriş / kayıt |
| `catalog.png` | Kitaplar ve filtreler |
| `recommendations.png` | Kitap önerileri |
| `my-ratings.png` | Puanlar ve yorumlar |

3. Ana README'deki `<!-- Görselleri ...` satırı ile ilgili kapanış `-->` satırını kaldırın. İçerideki başlıklar ve görsel satırları kalsın. Yalnızca elinizde olan görüntülerin satırlarını kullanın.
4. README ve görselleri birlikte GitHub'a gönderin. Dosya adları büyük/küçük harf dahil aynı olmalı.

Örneğin tek görüntü eklemek için ana README'ye şunu yazabilirsiniz:

```markdown
![Kitap kataloğu ve filtreler](docs/screenshots/catalog.png)
```

Gerçek ekran görüntüleri henüz eklenmedi. Mevcut `hero.png` arayüz varlığıdır; ekran görüntüsü olarak kullanılmadı.

İngilizce `README.md` ve Türkçe `README.tr.md` aynı görselleri kullanır. Görsel bloğunu her iki dosyada da açın; böylece dil değiştirildiğinde ekran görüntüleri görünür.
